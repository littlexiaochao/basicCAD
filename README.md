# basicCAD

极简的 CAD 3D 模型查看网页，基于 **Three.js + Vite** 构建。

## 功能

- 📂 **导入模型**：支持 OBJ / STL / STEP（.stp）格式，点击「导入模型」选择文件，或直接拖入页面
- 🧊 **STEP 支持**：通过 OpenCASCADE 的 WASM 版本（occt-import-js）把 STEP 精确曲面转为三角网格显示，并默认叠加 CAD 原始边界棱线（可按「着色模式 → 网格显示」开关）；解析在浏览器本地完成，无需后端
- 🖱️ **3D 交互**：左键旋转、右键平移、滚轮缩放
- 🧭 **视图立方体**：左下角 3D 立方体实时跟随相机旋转，点击面/边/角即可切换到对应视角
- 🔲 **投影切换**：视图立方体面板内「透视 / 正交」按钮一键切换投影模式
- 📐 **格线开关**：左侧「格线」按钮一键显示 / 隐藏网格
- 🎛️ **操作轴**：左侧「操作轴」下拉框包含移动 / 旋转 / 缩放模式与「移到原点」，选中后点击模型显示 X/Y/Z 手柄，可拖拽或输入数值（回车应用）
- ↩️ **撤销 / 重做**：`Ctrl+Z` 撤销、`Ctrl+Shift+Z`（或 `Ctrl+Y`）重做，支持变换操作的步骤缓存
- 📐 **CAD 坐标**：OBJ 自动从 Y-up 旋转为 Z-up；STL / STEP 保持其 Z-up CAD 坐标；XY 平面格线上 X/Y 中心线分别为红/绿色
- 🔄 模型加载后自动居中，并以等轴测视角适配视图
- 🧹 **清除模型**：一键清空当前模型并复位视图
- 📊 **模型信息**：左上角半透明面板显示顶点数与网格面数
- 🎨 **着色模式**：网格显示 / 平坦着色（三角面片法线）与光顺着色（顶点法线插值）切换 / 法线着色 / 环境贴图着色（勾选后下拉选择 7 种 Blender 环境贴图，带材质球预览，环境自动对齐 CAD 坐标，可隐藏背景不影响着色），法线着色与环境贴图互斥；「高光」滑块对 Phong/Standard 均有效、「环境反射」滑块（环境贴图着色内）调节金属反射、「固有色」「反面」颜色选择器（反面默认浅灰黄单色，可选正面着色）；关闭环境贴图着色时恢复默认 Phong 着色
- 🧊 **隐式表示（SDF）**：工具栏「隐式」下拉框设置分辨率后，点击「转换为隐式表示」将模型采样为规则网格 SDF（内部为正、外部为负），并**直接以免网格体绘制显示**（GPU 光线步进，只渲染最近表面、被遮挡部分不渲染，零网格提取）；「转化为网格」区可选**提取算法**（默认 Manifold 3D level set，也可切双轮廓 DC 保留锐边；只影响网格化、与隐式化解耦，采样时始终保存最近面法线，切 DC 无需重采样）并设置**网格化精度**滑块（1~3 倍 SDF 格距，越小越精细；实时影响免网格预览步长，网格化时作为提取密度），点击「网格化」将隐式表示提取为三角网格；网格化网格支持「显示网格边」（三角网格边叠加层，可开关）；提取后自动过滤极小连通分量（点状/杆状杂点）。**数据流**：画布顶部显示 `原模型 → 隐式表示 → 网格化` 阶段，点击任一文字切换当前显示（蓝色 = 正在显示，其余灰色），着色选项作用于当前显示的数据；「导出表面」按当前网格化精度导出 STL 二进制 / STL 文本 / OBJ，尚未网格化时自动先网格化。左上角信息面板分类显示模型区（顶点数 / 网格面数 / 网格封闭性）与隐式区（分辨率 / 内存 / 顶点数 / 三角面数）。采样采用 **OpenVDB / nTop 同款的窄带溅射**（只在表面附近计算精确距离，远处用常量兜底），成本与分辨率解耦，并且三角形区间按核数拆分给 **Web Worker 并行**（模型加载时预热 Worker 池，失败自动回退内联），溅射时顺带保存最近面法线供 **Hermite 数据**使用；为后续晶格化（如 Gyroid）与切割布尔预留了 `combineSDF` / `gyroidSDF` / `sampleLatticeSDF` 等接口

> 环境贴图 `public/env/*.exr` 来自 Blender 内置工作室光照（CC0 许可，由 Greg Zaal / Poly Haven 制作）。
- 🧪 **示例模型**：`public/models/sample-torus-knot.obj`，可通过「导入模型」加载测试

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建
npm run build

# 预览构建产物
npm run preview
```

```
basicCAD/
├── index.html            # 页面结构（简洁工具栏 + 3D 视口）
├── src/
│   ├── main.js           # 入口 + 模型导入逻辑
│   ├── style.css         # 深色极简主题样式
│   ├── sdf/
│   │   ├── implicit.js     # 隐式表示（SDF）核心：网格→SDF 采样、等值面提取、布尔组合、Gyroid 晶格函数
│   │   ├── splatKernel.js  # 窄带溅射共享内核（主线程 / Worker 共用，保存最近面法线）
│   │   ├── splatWorker.js  # Web Worker 并行溅射
│   │   ├── dualContour.js  # Hermite 数据 + Dual Contouring（QEF）等值面提取
│   │   └── meshExport.js   # 隐式表面网格导出（STL 二进制 / STL 文本 / OBJ）
│   └── viewer/
│       ├── Viewer.js     # Three.js 查看器核心类
│       ├── ViewCube.js   # 视口立方体（view cube）
│       └── implicitVolume.js # 免网格体绘制：GPU 光线步进直接渲染 SDF
└── vite.config.js
```

## 隐式表示与后续扩展

- **网格 → SDF**：`meshToSDF()` 用窄带溅射（splat）采样：每个三角形只向它 AABB 附近的格点溅射精确点面距离（窄带宽度覆盖壳体厚度 + 符号过渡带），远处用常量距离兜底，因此采样耗时随三角形数增长而非 N³。三角形区间相互独立，通过 `splatWorker.js` 按核数拆给 Web Worker 并行计算、主线程合并取最小值（结果与内联版逐位一致），小模型或 Worker 不可用时自动回退内联。再按模型封闭性处理：封闭模型用最近面法线符号 + 洪泛符号修正（`correctSignByFloodFill`，从网格边界扩散，消除孤立符号岛），开放模型直接输出 `厚度 - 无符号距离` 的壳体（封闭性判定以开放边/非流形边为准，退化细长三角形不影响，避免把含细长条的封闭模型误判为开放而加厚）。输出 N³ `Float32Array`（约定：内部为正、外部为负，与 Manifold.levelSet 一致）。
- **SDF → 网格**：默认用 **Hermite 数据 + Dual Contouring**（`dualContour.js`）提取等值面：溅射时顺带保存每个格点的最近面单位法线（`meshToSDF(collectNormals)`），每条穿越等值面的网格边记录交点 + 法线（法线取负值侧端点的溅射法线，避免角点“对角线”格点法线歧义），每个单元用 QEF（特征值截断到 1e-2 相对阈值，光滑面按秩 1 回退样本质心）解出唯一顶点，穿越边连接相邻单元顶点生成四边形，并用 SDF 梯度统一面朝向（内部为正 → 外法线与梯度反向）。相比 Manifold 的 Marching Tetrahedra：**保留锐边/尖角**（立方体角点偏差 ≈ 0），速度更快（不需要 WASM），显示精度滑块映射为粗网格步长（≤1.4→满分辨率、1.5~2.4→每 2 格取一、≥2.5→每 3 格取一），只重提取、不重算 SDF。Manifold 路径保留为可选项（`setExtractMethod('manifold')` / UI 下拉「提取算法」），`sdfToThreeMesh()` 通过 `Manifold.levelSet` 输出流形网格。
- **碎屑过滤**：`filterSmallComponents()` 按连通分量丢弃极小孤岛（默认 <24 面或 <0.2% 总面数），清除点状/杆状杂点。
- **布尔 / 切割**：网格级可用 Manifold 的 `union / difference / intersection`（保证流形输出）；体素级可用 `combineSDF()` 直接对 SDF 做 `min / max` 组合。
- **晶格化**：`gyroidSDF()` 提供 Gyroid TPMS 隐式函数，`sampleLatticeSDF()` 可将其采样成与模型一致的 SDF，再与模型 SDF 做交集即可在模型内部生成晶格（后续功能入口）。
